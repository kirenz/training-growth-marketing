```{=html}
Growth Loop
Der Output einer Runde ist der Input der nächsten
Ein abgeschlossenes Projekt wird zur Fallstudie. Die Fallstudie zieht passende Interessierte an. Aus Interessierten werden neue Projekte. Auf „Nächste Runde“ klicken, ein Klick auf einen Knoten erklärt ihn.
Beispielzahlen für den Mechanismus: je Fallstudie 4 Interessierte, jede zweite Anfrage wird ein Projekt.
```
