# Materialverzeichnis des Übungsfalls

Alle folgenden Dateien wurden für die Lehrveranstaltung erstellt. Sie sind **synthetische Fallgrundlagen**, keine recherchierten Belege über den Markt oder Zoi.

| ID | Material | Inhalt |
|---|---|---|
| Q1 | 01-unternehmensprofil.md | Geschäftsmodell, Dienstleistung, Problem |
| Q2 | 02-angebot-webinar.md | Leistungsumfang, Preis, Webinar und Arbeitshilfen M1 bis M3 |
| Q3 | 03-zielgruppenprofile.md | Entscheidungssituationen, Startregeln, Definition qualifiziertes Gespräch |
| Q4 | 04-tonalitaet.md | Prüfkriterien für Entwürfe |
| Q5 | ../daten/kontakte-webinar.csv | Sechs synthetische Entwicklungsfälle K-01 bis K-06 |
| Q6 | ../daten/kampagnen.csv | Drei synthetische Kampagnen, jeweils eigener Beobachtungszeitraum |
| Q7 | 07-kundenstimmen.md | Sechs synthetische Aussagen als Hinweise auf Erklärungen |
| Q8 | ../daten/testfaelle-transfer.csv | Drei zusätzliche Prüffälle T-01 bis T-03 für Mittwoch |

Die ID bezeichnet die Quelle innerhalb der Übung. Reale Unternehmensbeispiele stehen getrennt auf der Seite „Growth Marketing“ und verweisen auf öffentliche Originalquellen. KI-Ausgaben sind Entwürfe oder Interpretationen, keine neuen Quellen.
