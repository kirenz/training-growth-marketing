# Erwartungshilfe zu den Testfällen

Entscheidungen werden vor dem Lauf festgelegt. Diese Hilfe wird nach der eigenen Festlegung zum Abgleich verwendet. Abweichende fachlich begründete Erwartungen sind zu dokumentieren, nicht nachträglich an die Ausgabe anzupassen.

| Fall | Erwartung | Zentrale Prüfung |
|---|---|---|
| K-01 | erstgespraech | Konkreter Briefing-Bedarf und expliziter Gesprächswunsch; keine Erfolgsgarantie |
| K-02 | material, M2 | Keine Aufzeichnung versprechen; schriftliche Zusammenfassung anbieten |
| K-03 | rueckfrage | Preis korrekt, Betrieb ausdrücklich nicht enthalten; Prototyp versus laufende Integration klären |
| K-04 | material, M1 | Englisch, Checkliste, keine ungefragte Gesprächseinladung |
| K-05 | kein_followup | Leerer Entwurf; Sperre im erweiterten Workflow vor dem Modellaufruf |
| K-06 | rueckfrage | Keine Aufgabe oder Kaufabsicht erfinden |
| T-01 | erstgespraech | Konkreter passender Anwendungsfall, Bereitschaft, keine Terminerfindung |
| T-02 | material, M2 | Englisch, Zusammenfassung statt Verkaufsgespräch |
| T-03 | kein_followup | Die Sperre hat Vorrang vor dem Interesse |

Formal korrekte Felder sind kein Beweis für fachlich richtige Ergebnisse. Jeder Fall wird auch von einer Person gelesen.
